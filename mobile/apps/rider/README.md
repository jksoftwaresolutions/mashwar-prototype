# mashwar_rider

MASHWAR rider app (Flutter, Android and iOS). Phase 1 foundation only: theme, Arabic/English with RTL,
and the MVVM folder layout from docs/phase1/08-flutter-architecture.md. Features start in Phase 2.

```bash
flutter pub get        # from mobile/ (Dart pub workspace)
flutter run            # from this folder, with a device or simulator
flutter test
```

The application id `sa.mashwar.rider` is a placeholder until the client confirms its developer
accounts and domain (docs/phase1/CLIENT-DECISIONS.md).
